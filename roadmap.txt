ETAPA 4 - Dimensionamento da ficha (cortina/estaca em balanco) [x]
---------------------------------------------------------------------
METODO DA FOLHA MANUSCRITA DO USUARIO (cortina em balanco, SEM tirantes)
  Pa = gama*h*Ka - 2c*raiz(Ka)        Pp = gama*h*Kp + 2c*raiz(Kp)
  Ka = tg2(45 - phi/2)                Kp = tg2(45 + phi/2)
  Pa1 (topo): se negativo, considerar zero (depende da sobrecarga)
  Pp1 (nivel da escavacao) = 0
  Pa2A / Pa2B: empuxo ativo no nivel da escavacao (acima / abaixo da
  interface de camadas, se houver)
  Pp2 e Pa3: passivo e ativo na ponta C
  Ppe = Pp2 - Pa3   (passivo liquido na ponta C)
  x'  -> profundidade abaixo da escavacao onde o liquido se anula
         (PONTO DE GIRO O)
  x   -> distancia O-C, obtida de  soma(Mc) = 0:
         E1*y1 + E2*y2 - E3*y3 = 0
  Z = x + x'
  Ficha de projeto = 1,2 * Z
  Sentido: escavacao (passivo) a esquerda, solo contido + sobrecarga
  (ativo) a direita.

IMPLEMENTADO:
[x] Z obtido numericamente de soma(Mc)=0 (a ponta C muda o proprio
    diagrama, entao a equacao e nao linear; resolvido por varredura +
    bisecao, serve para multiplas camadas, coesao e sobrecarga)
[x] x' (ponto de giro) com camadas multiplas
[x] E1, E2, E3 e bracos y1, y2, y3 em relacao a C; conferencia
    E1*y1 + E2*y2 - E3*y3 = 0
[x] Pa1, Pa2A, Pa2B, Pa3, Pp1, Pp2, Ppe na notacao da folha
[x] Ficha de projeto = fator*Z (fator editavel, padrao 1,2)
[x] Fator de seguranca opcional no passivo (padrao 1,0 = sem reducao)
[x] Resumo: ficha teorica x projeto, comprimento total, Mmax, Vmax
[x] Botao "Usar ficha de projeto em D" e marcadores O / C / ficha de
    projeto no desenho esquematico
[x] Testes: areia homogenea com solucao fechada (Z = h/(9^(1/3)-1),
    x' = h/8, Mmax = 281,25 kN.m/m), FS no passivo, sobrecarga e um caso
    multicamadas com coesao conferido por integracao numerica
    independente - todos OK
[x] Conferido com o exemplo manual do usuario (h=3, q=10, A1 phi15 c10
    g17 / A2 phi35 g19 / P1 phi35 g19): folha x=2,17 ; Z=2,42 ; ficha
    1,2Z=2,9 ~ 3 m  ->  app x=2,170 ; Z=2,424 ; ficha 2,91 m  (OK)
    CAUSA da divergencia inicial: a folha desenha o ativo como TRIANGULO
    de 0 (topo) ate Pa21 (E1 = 20,62*3/2 = 30,9), enquanto o app cortava
    na profundidade real de tracao z0 = 0,94 m (E1 = 21,1 -> Z = 2,04).
    Agora a opcao "Pa1 = 0: triangulo de 0 no topo ate Pa2" vem MARCADA
    (padrao = folha). Desmarcada = corte exato em z0 (menos conservador).
[x] Esquema com os pontos de atuacao: setas e valores de Pa1, Pa2A, Pa2B,
    Pa3 (lado ativo) e Pp1, Pp2, Ppe (lado passivo) + linhas de O, C e
    ficha de projeto; o desenho passa a cobrir a ficha de projeto
[x] Abas dos resultados: Empuxos | Ficha | Diagramas (sem "Etapa")
[x] Corrigido: salvar projeto agora grava fator da ficha, FS do passivo e
    a opcao Pa1 linear
Pontos a confirmar com o usuario:
  - Pa2A x Pa2B: valor acima / abaixo da interface de camadas no nivel
    da escavacao (CONFIRMADO pela folha: Pa21 = 20,62 e Pa22 = 16,47)
  - E2 e E3 sao areas do diagrama LIQUIDO (ativo - passivo), como na

PREMISSAS A CONFERIR COM CALCULO MANUAL DO USUARIO:
  - plano virtual em x = B; passivo frontal desprezado por padrao
  - beta (terreno inclinado) so altera Ka; peso do aterro inclinado nao modelado
  - Coulomb: Ea,v = Ea,H.tg(delta) soma ao peso
  - sobrecarga sobre o talao so estabiliza se a opcao estiver marcada
  - capacidade de carga sem fatores de profundidade
  - solo de fundacao = camada passiva na profundidade Df
  - FS padrao: tombamento 2,0; deslizamento 1,5; capacidade 3,0
